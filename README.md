# 高德服务商增长工作台 MVP

这是一个基于 Streamlit 的后台原型，用来快速验证“平台如何赋能服务商拓商、促付费、做交付、带续费”这条主链路。

## 当前已实现

- 首页总览
- 拓商工具
- 销售工具
- 商家与交付
- 批量交付
- 续费工具
- 平台管理台
- 平台首页
- 任务中心
- 统一时间线
- 操作日志
- 导出中心
- 沟通协同
- MVP 架构说明

## 适合演示的业务链路

1. 从潜客线索池筛出高意向商家
2. 查看门店经营诊断卡
3. 在销售工具中选择推荐套餐并生成报价
4. 进入商家与交付页面查看曝光、电话、导航、到店等指标
5. 进入批量交付页面查看连锁门店、批量任务和素材分发
6. 在续费工具中查看风险预警和复盘摘要
7. 在平台管理台中查看服务商认证、分级、激励、客诉和联合拜访
8. 在沟通协同里查看服务商与商家的沟通渠道、状态和摘要

## 本期刻意没有做的内容

- 真实投放系统对接

## 运行方式

```bash
streamlit run app.py --server.port 8510
```

如果 `8510` 端口被占用，可以换成别的端口，例如：

```bash
streamlit run app.py --server.port 8511
```

## 线上部署

当前项目已经补齐了基础部署文件，优先推荐直接部署到 `Streamlit Community Cloud`，也可以部署到 `Render / Railway` 这类支持 Python Web 服务的平台。

### 已补齐的部署文件

- `requirements.txt`
- `packages.txt`
- `.streamlit/config.toml`

### Streamlit Community Cloud

1. 把当前项目推到 GitHub 仓库
2. 登录 [Streamlit Community Cloud](https://share.streamlit.io/)
3. 选择仓库和分支
4. Main file path 填 `app.py`
5. 点击 Deploy

### 部署注意事项

- 当前数据默认保存在项目内的 `data_store/app_state.db`
- 这类托管平台的本地磁盘通常不是持久化存储
- 也就是说：如果实例重启，演示中新增或修改的数据可能会丢失
- 如果你要做长期在线版本，下一步建议把数据层从本地 SQLite 升级到云数据库

### 海报导出说明

- 项目已经兼容云端 Chrome / Chromium 查找
- 如果部署环境没有可用浏览器，点击海报按钮时会给出明确提示，不会直接报错

## 文件说明

- `app.py`：后台原型主程序
- `gaode_console/data.py`：示例数据层
- `gaode_console/storage.py`：轻量持久化层，基于本地 JSON
  现已升级为优先使用 SQLite，本地数据库文件位于 `data_store/app_state.db`
- `gaode_console/styles.py`：页面样式和视觉组件
- `gaode_console/pages.py`：各模块页面渲染逻辑
- `高德服务商赋能体系可视化分析.md`：前期策略分析稿
- `高德服务商赋能体系可视化分析.pdf`：可视化汇报版 PDF
